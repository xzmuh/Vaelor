# Vaelor — Documentação do Projeto

Esta pasta contém a base oficial do projeto **Vaelor**. Ela foi organizada para ser colocada diretamente dentro do repositório e utilizada como contexto permanente durante o desenvolvimento do site.

O site é a primeira manifestação pública de Vaelor, mas não é o centro da documentação. A base é o universo. A interface, as animações, os textos, os personagens apresentados e a ordem das seções devem nascer da história que já foi definida, sem transformar o projeto em uma coleção de telas bonitas desconectadas.

A documentação não tenta preencher lacunas com ideias aleatórias. Tudo que aparece como fato foi discutido e aceito até aqui. Tudo que ainda não possui resposta está claramente tratado como mistério, decisão pendente ou conceito provisório.

## Ordem de leitura

O arquivo `docs/00_PROJECT_CONTEXT.md` oferece a visão geral. Depois dele, a leitura deve seguir a numeração das pastas.

A base do mundo está em `docs/01_world/`. A premissa narrativa e os personagens estão em `docs/02_narrative/`. A tradução desse universo para a experiência digital está em `docs/03_website/`. As regras para continuar o projeto sem quebrar o cânone estão em `docs/04_production/`.

## Regra principal

Antes de criar qualquer página, texto, componente, imagem, personagem, facção, região ou efeito visual, o desenvolvimento deve consultar esta documentação.

Quando uma informação não estiver definida, ela não deve ser inventada silenciosamente. O correto é usar um marcador provisório, registrar a dúvida no arquivo de decisões pendentes e continuar apenas com o que já é seguro.

Vaelor deve crescer por decisão, não por preenchimento automático.
