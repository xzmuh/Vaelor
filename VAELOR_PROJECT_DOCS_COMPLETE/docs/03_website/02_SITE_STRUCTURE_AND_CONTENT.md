# Estrutura e Conteúdo do Site

## Carregamento

O carregamento deve ser simples e coerente com a atmosfera. Ele existe para preparar vídeo, imagens e áudio necessários para a entrada. Não deve usar textos explicativos longos.

A marca Vaelor pode aparecer de forma discreta. Nenhuma frase definitiva foi aprovada para essa tela.

## Entrada

A tela de entrada apresenta o nome Vaelor, um fundo cinematográfico e uma ação clara para entrar.

O fundo pode sugerir céu, nuvens, ruínas, energia ou uma paisagem ampla, mas o asset final ainda não foi escolhido. A entrada deve transmitir mistério antes de explicar o mundo.

## O mundo

Esta seção introduz a ideia de que Vaelor já foi guiado pela exploração e que o Cisma alterou seu destino. Ela apresenta as Alturas e as Fendas como as duas grandes fronteiras do desconhecido.

O conteúdo visual pode contrastar céu e abismo. O texto deve ser curto, derivado da World Bible e sem inventar causas para o Cisma.

## Afinidades

A seção apresenta Nival, Cruor e Voltis.

Cada Afinidade precisa possuir linguagem visual própria, mas a identidade deve nascer de sua natureza: frio para Nival, sangue ou vida para Cruor, eletricidade para Voltis.

A seção também pode sugerir instabilidade, porque esse fenômeno move a história atual.

## Personagens

Fuyuka, Akane e Miyari são os três destaques iniciais.

Cada personagem pode possuir uma seção quase em tela cheia, com:

- nome;
- Afinidade;
- uma frase curta;
- arte ou vídeo;
- interação discreta para ver mais.

Os textos ainda devem ser conceituais, porque as histórias completas não foram definidas.

## Facções

A seção deve apresentar as três direções de conflito: alcançar as Alturas, explorar as Fendas e reproduzir Afinidades artificialmente.

Como os nomes oficiais não existem, o desenvolvimento não deve gravar nomes genéricos como se fossem definitivos. É possível trabalhar com títulos descritivos internos e manter a apresentação pública pendente.

## Encerramento

O encerramento reforça que a jornada está começando. Pode recuperar o nome Vaelor, a ideia da Faísca ou a imagem de uma fronteira ainda não alcançada.

Nenhuma chamada final, slogan ou data de lançamento foi definida.

## Navegação

A navegação deve ser mínima e servir como suporte. O visitante pode acompanhar o fluxo vertical, mas deve conseguir acessar seções principais sem se perder.

## Responsividade

A experiência precisa funcionar em desktop e mobile. A versão mobile não deve ser apenas uma redução proporcional do desktop. Vídeos, textos, interação e ritmo precisam ser adaptados.

## Acessibilidade

Motion deve respeitar preferências de redução de movimento. Vídeos precisam de fallback. Contraste e legibilidade não podem ser sacrificados pela estética. Áudio deve possuir controle claro.

## Conteúdo separado do código

Textos, nomes, Afinidades, mídias e configurações de personagem devem ficar em arquivos de conteúdo ou estruturas de dados fáceis de atualizar.

O código não deve esconder decisões narrativas em componentes.
