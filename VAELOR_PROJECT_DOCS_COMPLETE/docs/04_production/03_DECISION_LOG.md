# Registro de Decisões

## Aprovado

**Vaelor** é o nome do mundo.

O projeto começa pelo website, mas toda a documentação deve preservar o peso da história.

A documentação deve ser legível como uma World Bible, não como uma wiki fragmentada.

O site deve funcionar como primeira entrada pública para a IP.

As Afinidades conhecidas são Nival, Cruor e Voltis.

Fuyuka, Akane e Miyari formam o trio inicial de personagens planejadas.

A Faísca do protagonista não é uma Afinidade.

## Rejeitado

**Astera** foi rejeitado como nome do mundo.

**Convergência** foi rejeitado como nome do fenômeno que cria portadores.

**Centelha** foi rejeitado como nome do fenômeno que cria portadores.

Uma documentação excessivamente fragmentada, composta por dezenas de arquivos curtos e listas, foi rejeitada.

## Provisório

**Cisma** é o nome atual do grande acontecimento, mas pode ser substituído.

**Coroa** foi considerado para a facção militar e científica, mas não está aprovado.

A estrutura do site é provisória e pode evoluir sem perder a ordem narrativa central.

## Sem decisão

O nome do jogo ou da IP.

Os nomes das facções.

A geografia política e regional.

A origem da Faísca.

A causa do Cisma.

A verdade sobre as Alturas.

A verdade sobre as Fendas.
