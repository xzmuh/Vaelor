# VAELOR

Vaelor é uma IP original de fantasia com foco em exploração, mistério e personagens no estilo gacha.

## Pilares

- Mistério acima das nuvens.
- Mistério nas profundezas.
- Exploração.
- Afinidades elementais.
- Personagens marcantes.
- Experiência cinematográfica.

O objetivo inicial é construir um site de apresentação inspirado na qualidade de execução de Genshin Impact, porém com identidade própria.
