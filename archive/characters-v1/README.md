# Personagens — primeiro modelo preservado

Esta pasta guarda uma cópia fechada da primeira versão da página de personagens,
incluindo o componente, a folha de estilos daquele momento e todas as imagens
necessárias para restaurá-la.

- `CharactersPage.tsx`: componente original.
- `styles.snapshot.css`: estilos completos usados pela versão.
- `public/chars/`: imagens diretamente referenciadas pelo componente.

O arquivo original também continua intacto em `src/CharactersPage.tsx`.
